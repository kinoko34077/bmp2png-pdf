# BMP/PNG圧縮とPDF作成ツール 仕様書

- 更新日: 2026-10-09
- 対象: `kinoko34077/bmp2png-pdf`

## 概要

BMPとPNGを可逆圧縮PNGに変換するWindowsデスクトップアプリです。必要に応じて、変換後のすべてのPNGを一覧順で単一PDFにまとめます。処理はPC内で完結し、配布版の利用にPythonやネット接続は不要です。

## 入力と順番

- `.bmp` と `.png` をファイル選択またはドラッグ＆ドロップで追加できます。拡張子の大文字・小文字は問いません。
- 重複パスは一つにまとめます。
- 追加時はファイル名の自然順（大文字小文字を区別せず、数字部分は数値として比較）で並べます。
- 一覧をドラッグ、または「上へ」「下へ」ボタンで並べ替えられます。現在の順番をPNG変換とPDFページ順の両方に使います。

## PNG変換

- 圧縮レベルは0〜9で、初期値は9（高圧縮）です。PNG圧縮は可逆で、画素データは劣化しません。
- 入力のピクセルとアルファ情報を保ち、DPI情報があれば出力PNGへ引き継ぎます。
- BMP入力は従来どおり同じベース名のPNGを作ります。PNG入力はファイル名に接尾辞を加えます。初期値は `_compressed` です。
- 出力先を指定するとすべてのPNGをそのフォルダーへ保存します。指定しない場合は各入力ファイルと同じフォルダーです。
- 「上書きする」は初期状態オフです。オフなら既存ファイルを残し、出力名に連番を付けます。オンなら既存の同名出力を置き換えます。
- 同一実行内の同名出力は連番で分けます。選択中の入力ファイルは、上書き設定にかかわらず保護します。
- 各PNGは一時ファイルへ完成させてから出力名を確定します。変換失敗時は成功したPNGを残して失敗を表示し、PDFは作成しません。

## PDF

- 「PDFにする」チェックボックスで任意に作成できます。PDF名入力欄を使い、保存先はダイアログで指定します。拡張子がなければ `.pdf` を補います。
- 全PNGの変換が成功した後に限り、一覧順で全画像を含むPDFを一つ作成します。BMPまたはPNGごとの個別PDFは作りません。
- 画像1枚につきA4 1ページとし、画像の向きに合わせてページを縦または横にします。縦横比を維持し、余白内に配置します。
- ラスター画像を再サンプリングせず、元画像のDPIを配置寸法に反映します。PDF初期表示はページ全体表示（Fit）・単ページ表示です。
- 「上書きする」の設定をPDFにも適用します。PDFの出力先が入力画像や今回のPNG出力と衝突する場合は保護して別名にします。
- PDF作成に失敗しても完成したPNGは保持し、不完全なPDFは確定しません。

## 技術構成と配布

- Python 3.12、Tkinter、tkinterdnd2、Pillow、ReportLab、pypdfを使用します。
- PDFライブラリ比較ではimg2pdfが高速・小容量でしたが、追加依存が約20.9MiBとなるため、配布物を軽く保つ目的でReportLab+pypdfを採用します。
- Nuitka one-file形式でWindows x64向けの単一EXEを作ります。展開先は `%LOCALAPPDATA%\kinoko34077\bmp2png-pdf\<version>` に固定し、更新版は異なる版フォルダーを使います。one-fileは起動時に展開処理があり、固定先の使用だけでは2回目以降の高速化を保証しません。実機での起動時間は未測定です。アプリ利用者に管理者権限、Python、Cコンパイラー、ネット接続は不要です。
- ビルド側はPython 3.12とネット接続を使い、Nuitka対応のMinGW64コンパイラーを取得します。コンパイラーはリポジトリ内キャッシュに置きます。GitHub Actionsでも同じビルドスクリプトを使います。
- ライセンスは未選択です。GitHub Releaseやバイナリ公開はdevflowの公開ゲートに従い別途行います。

